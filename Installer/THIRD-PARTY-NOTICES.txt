Separate guild server components, NOT included in this installer
----------------------------------------------------------------

Speech recognition runs on the guild server. The Vemal's Ears member app
receives caption text and never downloads these server components. The
server operator's tooling pins its downloads in VoiceCaptions/runtime_installer.py:

- whisper.cpp (build b4938), licensed under the MIT License.
  Two builds: a CPU one, and a CUDA/cuBLAS one shown by server tooling as
  the "NVIDIA speech engine". The NVIDIA CUDA runtime libraries inside
  that second archive remain subject to NVIDIA's own licence terms.
- Whisper large-v3-turbo speech model, by OpenAI, licensed under the MIT
  License. Obtained as the ggml quantisation ggml-large-v3-turbo-q5_0.
- Silero VAD 6.2.0, licensed under the MIT License. Used as the local
  speech gate, so silence never reaches the transcriber.

Bundling any of these into the installer instead of the server downloading them
would make this project a redistributor of them, and this file would
have to carry their full terms. That is the
reason the download happens at runtime.

https://github.com/ggml-org/whisper.cpp
https://github.com/openai/whisper
